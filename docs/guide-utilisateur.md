# Guide utilisateur

## Visiteur

Utilisez la navigation pour découvrir les services, les articles et les
réalisations. Dans le blog, choisissez une catégorie pour filtrer les articles.
Dans le portfolio, les badges indiquent la catégorie et les tags de chaque
réalisation.

## Client

Créez un compte, vérifiez votre email, puis connectez-vous pour accéder au
dashboard. Vous pouvez y déposer une demande de devis et suivre vos tickets.

## Administrateur

Depuis le dashboard, utilisez les fenêtres de gestion pour créer ou modifier
les articles et les projets. Une catégorie est obligatoire pour un article ; un
projet peut recevoir jusqu'à dix tags.
